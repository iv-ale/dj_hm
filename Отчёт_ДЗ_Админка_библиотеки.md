# Отчёт по домашнему заданию: Админка библиотеки

Приложение: `books` (модели `Author` и `Book`), проект `config`, Django 6.1.3.

## 1. Админка библиотеки

`books/admin.py`, класс `BookAdmin`:

* `list_display` — колонки: Заголовок, Автор, Год издания, Страниц, Статус, В наличии;
* `list_filter` — фильтры: статус, в наличии, год издания, автор;
* `search_fields` — поиск по названию книги и имени автора (`title`, `author__name`);
* `ordering` — сортировка по названию, заголовок кликабелен (`list_display_links`);
* `list_select_related` — автор подгружается одним запросом (нет N+1).

`AuthorAdmin`: колонки Имя, Email, Дата рождения, число книг (annotate `Count`),
фильтр по дате рождения, поиск по имени и email, сортировка по имени.

## 2. Inline

`BookInline(admin.TabularInline)` подключён к `AuthorAdmin.inlines` —
на странице автора отображается таблица его книг с возможностью
добавлять/редактировать книги прямо на месте.

## 3. Действия

Два своих действия в `BookAdmin.actions`:

* **«Выдать»** (`issue_books`) — книги со статусом «в наличии» → «выдана», `in_stock=False`;
* **«Списать»** (`write_off_books`) — все, кроме уже списанных → «списана», `in_stock=False`.

Оба действия требуют права `change` и показывают сообщение с числом
обработанных книг.

## 4. Сотрудник

Команда `python manage.py setup_library`:

* создаёт группу **«Библиотекари»** с 4 правами только на книги
  (`add_book`, `change_book`, `delete_book`, `view_book`);
* создаёт пользователя `librarian` (пароль `librarian123`), `is_staff=True`,
  `is_superuser=False`, добавляет его в группу.

Проверка прав: у сотрудника есть `books.*`, нет `auth.view_user` и
`auth.view_group` — в админке он видит только раздел «Библиотека → Книги»,
страницы пользователей/групп возвращают 403.

## Проверка

```
python manage.py test        # 13 тестов, OK (books: 5, shop: 8)
python manage.py check       # без ошибок
```

Тесты `books/tests.py` покрывают: колонки/фильтры/поиск, таблицу книг на
странице автора, действия «Выдать»/«Списать», видимость только книг
для сотрудника и 403 для чужих разделов.

## Запуск

```
python manage.py migrate
python manage.py setup_library   # группа и сотрудник
python manage.py runserver
```

Вход в админку под сотрудником: `/admin/` — `librarian` / `librarian123`.
